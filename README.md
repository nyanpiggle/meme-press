# Meme Press

Classic caption studio. Upload or pick an image, drag top and bottom text, tweak font size and outline, apply layout presets, and download a PNG.

## Open it

- **GitHub Pages** (after you enable it once): https://nyanpiggle.github.io/meme-press/
- **Local:** open `index.html` in any modern browser. No build step.

Pages is not live yet. One-time setup:

1. Repo **Settings → Pages**
2. Source: **GitHub Actions**
3. Re-run the **Deploy Pages** workflow (Actions tab), or push any commit

## Use

1. Pick a photo template, a paper/ink background, or upload your own.
2. Type top and bottom captions.
3. Drag captions on the image.
4. Font size + outline sliders, or a layout preset (Classic, Top Heavy, Bottom Line, Centered, Modern Bar).
5. Download PNG. Reset restores captions and style without clearing the current image.

## Files

- `index.html` / `styles.css` / `app.js` — the whole app
- `templates/` — Unsplash starter photos
- `ATTRIBUTION.md` — photo credits
- `GROK_BOT_INSTRUCTIONS.txt` — paste this into Grok Bot to continue the work
