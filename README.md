# Meme Press

Classic caption studio. Upload or pick an image, drag top and bottom text, tweak font size and outline, apply layout presets, and download a PNG.

## Open it

- **Live:** after GitHub Pages deploys, visit https://nyanpiggle.github.io/meme-press/
- **Local:** open `index.html` in any modern browser (no build step).

## Use

1. Pick a paper/ink template or upload your own photo.
2. Type top and bottom captions.
3. Drag the captions on the image.
4. Adjust font size and outline, or tap a layout preset (Classic, Top Heavy, Bottom Line, Centered, Modern Bar).
5. Download PNG. Reset restores captions and style without clearing your image.
